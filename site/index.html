Think in maps.

A free, open-source mind mapping app that opens in an instant, works offline and keeps every map in a file you own. And Claude can work on the same map you do.

Download free View on GitHub

Free and open source · Version 0.5: select several topics by dragging, and tables in the cards

Built for fast thinking

All from the keyboard, no waiting.

The mind map lays itself out while you type.

Select and type

Text goes straight into the topic. Tab adds a child, Enter a sibling, both ready for typing; the arrow keys move around the map.

On both sides

Branches to the left and right of the central topic. Pick each branch’s side from the right-click menu.

Notes on every topic

Short text on the map, details in a Markdown note saved right along with it.

Real undo

Two hundred steps back and forth, without losing what you collapsed or moved to the other side.

Search the map

Finds by text or note, and highlights every matching topic.

Works offline

No account, no server. Local-first: the map is a file on your computer.

Claude

Claude on the same map.

Nodo has a built-in MCP server, so AI agents like Claude can edit your maps. Turn it on in Settings and ask Claude to read, create and reorganize your mind maps.

The same rules as an edit by hand

It uses the same core as the app: each of its edits goes into the same history, and it can undo what it did.

  • Claude Desktop: one button in Settings
  • Claude Code: one command to paste into the terminal
  • When Claude saves, the window reloads the map as soon as you return to it
Your maps

Your style, in your own file.

Themes for the map and for the window, and an open file format you can read without the app.

Map themes

Six themes in the spirit of XMind, so it feels familiar if you are looking for an XMind alternative: colored cards, outline, text on the line, bold colors, pills or grays. Each main branch gets a color and the ones below inherit it. The theme is saved in the map itself.

The file is yours

Every map is a .nodo file: a zip with the map as readable JSON plus its attachments, which you can open without the app. Saving never leaves a half-written file. Minder (.minder), Markdown and OPML files open as new maps.

Looks at home on your system

Light and dark themes, and a System theme that matches the colors of Windows, macOS, GNOME and KDE. Curved or angled branches, with rounded corners. It works in a narrow window too.

Structures and formats

Any shape your thinking takes.

Switch the whole map’s structure in one click, and move your ideas in and out in open formats.

Seven structures

Mind map, logic chart, org chart, tree, matrix, tree table and timeline, with compact, normal or wide spacing. The structure is saved in the map and can be undone.

Markdown and OPML import and export

Open Markdown, OPML and Minder files as new maps. Export to PNG, SVG, a print-ready PDF, Markdown or OPML.

Every topic is a card

A Markdown note, tags, an emoji, a reminder, a three-color status, photos and attachments. Copy a card into Ideario, or paste one from it.

Several maps in tabs

Keep many maps open at once and switch with Ctrl+Tab. Closing one with unsaved changes asks before it goes.

Linux

From the apt or dnf repository, which updates along with your system (commands below). Or the .AppImage, which runs on any distribution and updates itself.

Download

Linux, from the repository

This way Nodo updates along with the rest of your system. Ubuntu, Debian and derivatives:

curl -fsSL https://nodo-1c7.pages.dev/linux/nodo.gpg | sudo tee /usr/share/keyrings/nodo.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/nodo.gpg] https://nodo-1c7.pages.dev/apt stable main" | sudo tee /etc/apt/sources.list.d/nodo.list
sudo apt update && sudo apt install nodo

Fedora:

sudo curl -fsSL -o /etc/yum.repos.d/nodo.repo https://nodo-1c7.pages.dev/linux/nodo.repo
sudo dnf install nodo
