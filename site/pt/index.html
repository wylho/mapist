Pense em mapas.

Um app de mapas mentais grátis e de código aberto que abre num instante, funciona sem internet e guarda cada mapa num arquivo seu. E o Claude pode trabalhar no mesmo mapa que você.

Grátis e de código aberto · Versão 0.3: formato .nodo, e cada tópico é um card

Feito para pensar rápido

Tudo pelo teclado, nada de esperar.

O mapa se arruma sozinho enquanto você escreve.

Selecione e digite

O texto entra direto no nó. Tab cria um filho, Enter um irmão, já prontos para escrever; as setas andam pelo mapa.

Dos dois lados

Ramos à esquerda e à direita da raiz. Escolha o lado de cada um no clique direito.

Notas em cada nó

Texto curto no mapa, detalhes na nota em Markdown, que fica guardada junto.

Desfazer de verdade

Duzentos passos para trás e para a frente, sem perder o que você recolheu ou mudou de lado.

Busca no mapa

Encontra pelo texto ou pela nota, e marca cada nó que bate.

Sem internet

Nenhuma conta, nenhum servidor. Local-first: o mapa é um arquivo no seu computador.

Claude

O Claude no mesmo mapa.

O Nodo traz um servidor MCP embutido, para agentes de IA como o Claude editarem seus mapas. Ligue nas Configurações e peça ao Claude para ler, criar e reorganizar seus mapas mentais.

As mesmas regras de uma edição à mão

Ele usa o mesmo núcleo do app: cada edição dele vai para o mesmo histórico, e ele também desfaz o que fez.

  • Claude Desktop: um botão nas Configurações
  • Claude Code: um comando para colar no terminal
  • Quando o Claude salva, a janela recarrega o mapa ao voltar para ela
Seus mapas

Com a sua cara, no seu arquivo.

Temas para o mapa e para a janela, e um formato aberto que se lê sem o app.

Temas de mapa

Seis temas, no espírito do XMind: cartões coloridos, contorno, texto sobre a linha, cores fortes, pílulas ou cinzas. Cada ramo principal ganha uma cor e os de baixo herdam. O tema fica salvo no próprio mapa.

O arquivo é seu

Cada mapa é um arquivo .nodo: um zip com o mapa em JSON legível e os anexos, que abre sem o app. Salvar nunca deixa um arquivo pela metade. Mapas .minder, Markdown e OPML abrem como mapa novo.

Com a cara do seu sistema

Temas claro e escuro, e um tema Sistema que imita as cores do Windows, do macOS, do GNOME e do KDE. Ramos em curva ou em ângulo, com cantos arredondados. Funciona também numa janela estreita.

Estruturas e formatos

Do jeito que a ideia pedir.

Troque a estrutura do mapa inteiro com um clique, e leve suas ideias para dentro e para fora em formatos abertos.

Sete estruturas

Mapa mental, diagrama lógico, organograma, árvore, matriz, tabela em árvore e linha do tempo, com espaçamento compacto, normal ou largo. A estrutura fica salva no mapa e se desfaz.

Importa e exporta Markdown e OPML

Abra arquivos Markdown, OPML e do Minder como mapa novo. Exporte em PNG, SVG, PDF para imprimir, Markdown ou OPML.

Cada tópico é um card

Nota em Markdown, etiquetas, emoji, lembrete, status em três cores, fotos e anexos. Copie um card para o Ideario, ou cole um que veio de lá.

Vários mapas em abas

Deixe vários mapas abertos e troque com Ctrl+Tab. Fechar um com algo por salvar pergunta antes.

Baixar

Grátis e de código aberto.

Os instaladores para Windows, macOS e Linux ficam na página de versões do GitHub. Depois de instalado, o Nodo avisa quando sai versão nova e se atualiza sozinho.

Windows

O -setup.exe (ou o .msi).

Baixar

macOS

O .dmg, para Apple Silicon e Intel. Na primeira vez, clique com o botão direito no app e escolha Abrir: ele ainda não é assinado pela Apple.

Baixar

Linux

Pelo repositório apt ou dnf, que atualiza junto com o sistema (comandos abaixo). Ou o .AppImage, que roda em qualquer distribuição e se atualiza sozinho.

Baixar

Linux, pelo repositório

Assim o Nodo atualiza junto com o resto do sistema. Ubuntu, Debian e derivados:

curl -fsSL https://nodo-1c7.pages.dev/linux/nodo.gpg | sudo tee /usr/share/keyrings/nodo.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/nodo.gpg] https://nodo-1c7.pages.dev/apt stable main" | sudo tee /etc/apt/sources.list.d/nodo.list
sudo apt update && sudo apt install nodo

Fedora:

sudo curl -fsSL -o /etc/yum.repos.d/nodo.repo https://nodo-1c7.pages.dev/linux/nodo.repo
sudo dnf install nodo

Sem anúncios, sem rastreamento, sem coleta de dados. Leia a Política de Privacidade.
